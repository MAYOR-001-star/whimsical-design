What a start.ng game is

A static, prebuilt website in a public GitHub repo. Frontend only: no server code, no secrets, no password fields. Use relative paths, and your game should run without a build step.

The name and the address

Your game's name becomes its address.

<name>.start.ng yourgame.start.ng

Lowercase letters, numbers and hyphens, up to 40 characters. Some names are reserved, and the first owner keeps a name.

Put your game live

1

Build the game so it runs without a build step, and commit the built folder.

2

Push it to a public GitHub repo.

3

Call the check endpoint and fix anything it reports.

4

Call the publish endpoint.

5

For a new game, open the link you get back once to approve it. After that, every push to the branch updates the game automatically.

API reference

check, then publish
POST https://api.start.ng/games/check
POST https://api.start.ng/games/publish

{
  "repo_url": "https://github.com/you/your-game",
  "name": "your-game",
  "branch": "main"
}
Body (JSON)

repo_url required, a public GitHub repo
name optional
branch optional

Responses

202 new game, with an approve_url
200 update to a live game

Players and scores

Your game talks to start.ng through a hidden iframe at start.ng/connect using postMessage. Games with a character should draw from the player's style; games without one should show a profile card. Guests get the default look and a sign-in option.

startng:whoamistartng:scorestartng:leaderboardstartng:ticket

A plain score works out of the box. For custom columns, define 1 to 5 stats in a startng.json file.

  • ★Cover image: cover.png, .jpg or .webp at 16:10, at least 640×400, under 2 MB.
  • ★Scores: whole numbers from 0 to 1,000,000,000. The best run is kept per player.
  • ★Warnings: external scripts, insecure links and redirects trigger warnings. Malware, crypto miners or hidden programs block publishing.
  • ★Rate limit: unsigned new-game publishing is limited to 20 per hour per address.

Checklist before you publish

  • Runs with no build step, built folder committed
  • Public GitHub repo
  • Relative paths, frontend only, no secrets, no password fields
  • A valid name and a 16:10 cover image
  • The check endpoint reports no errors
